## Installation

```bash
python -m venv venv
venv\Scripts\Activate.ps1      # Windows
pip install -r requirements.txt
```

Then open the relevant week's notebook (see each week's README for the exact path) in VS
Code or Jupyter and select the `venv` kernel.
