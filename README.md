# AnalystLab Africa – Data Science Internship

This repo holds my weekly work for the AnalystLab Africa Data Science Internship — one dataset
(Loan Prediction, after Week 1's separate HR attrition project), carried forward and built on
week by week rather than restarted each time.

## Weeks

- **[Week 1](Week%201%20Assignment/README.md)** — Employee attrition exploration (IBM HR dataset). A separate warm-up project before settling on the Loan Prediction dataset used from Week 2 onward.
- **[Week 2](Week%202%20Assignment/README.md)** — Cleaning and preparing the Loan Prediction dataset for machine learning.
- **[Week 3](Week%203%20Assignment/README.md)** — Statistical testing and feature engineering on top of the Week 2 cleaned dataset.

## Setup

```bash
python -m venv venv
venv\Scripts\Activate.ps1      # Windows
pip install -r requirements.txt
```

Each week's notebook lives under its own folder — open the relevant one and select the `venv`
kernel.
